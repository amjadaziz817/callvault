# Store images for F-Droid

Add these image files before you submit to F-Droid. F-Droid needs real image
files, so this folder holds a note, not the images.

Required:
- `icon.png` — 512 x 512 px app icon.

Recommended:
- `phoneScreenshots/1.png` — the main screen.
- `phoneScreenshots/2.png` — the deal form.

Export the icon from `app/src/main/res/drawable/ic_launcher_foreground.xml` on
the teal background, or draw a new one.
