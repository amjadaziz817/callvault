# CallVault — Keyword Research (India and Pakistan)

This file lists the target keywords for CallVault. It covers India and Pakistan.

> **Important:** The volume numbers below are **estimates**. Treat them as a
> guide for priority, not as exact data. Confirm each number in Google Keyword
> Planner, Ahrefs, or Semrush before you plan content. Enter the target country
> in the tool, because the volume differs a lot by country.

## How to read this file

- **Volume band** = the estimated monthly search count.
  - Very high = 50,000+
  - High = 10,000–50,000
  - Medium = 1,000–10,000
  - Low = under 1,000
- **Difficulty** = how hard it is to rank on page 1.
- **Intent** = what the user wants.
- **Target page** = the page that should rank for the keyword.

## 4. Keywords to avoid

Do not target these words. They can get the repository flagged as stalkerware,
and they attract the wrong users.

- "spy call recorder"
- "hidden call recorder to catch cheating"
- "record someone else's calls"
- "secret call recorder without them knowing"

Use neutral words: "automatic", "call recorder", "without root".

## 6. Off-page SEO

- Submit the app to **F-Droid**. F-Droid pages rank well on Google.
- Add the GitHub repository topics: `call-recorder`, `android`, `accessibility-service`, `no-root`, `open-source`.
- Post the project on Reddit (r/androidapps, r/fdroid) and on XDA. These give backlinks.
- Add the site to **Google Search Console** and submit `sitemap.xml`.
